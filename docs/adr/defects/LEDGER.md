one that matters, and `SHAPES.md` for the derived catalogue that feeds review briefs.

**Severity**: `S0` = destroys data and reports success (CLAUDE.md rule 6). `S1` = wrong result a user
would act on. `S2` = misleading output, no data loss. `S3` = internal/doc inaccuracy.

**Confidence**: `measured` = reproduced during this project's own work, numbers taken from a run.
`reconstructed` = backfilled from doc comments and ADRs after the fact; the shape is reliable, the
incidental detail is not.
